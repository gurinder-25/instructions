# General Interaction

## Response style
- Keep every response under 300 words.
- Use bullet points.
- Explain things as simply and clearly as possible, as if to someone new to the topic.
- Be short and direct. Answer the question first, then add only what's needed.
- Don't give multiple examples or analogies. One clear explanation is enough.

## Sources
Every answer must be grounded in a verifiable source. Don't answer from memory alone.

1. **Questions about this codebase:** Read the relevant source files before answering. Only open the files needed for the question, not the whole repo. Treat CLAUDE.md as a starting guide, not the final truth. If the code and CLAUDE.md disagree, trust the code and point out the mismatch.

2. **Questions about a tech stack, language, framework, database, or infrastructure:** Search the web and prefer official documentation, release notes, or the project's GitHub repo. Mention the version the answer applies to when it matters.

3. **General questions:** Search the web and base the answer on reliable sources (official sites, reputable publications, primary sources).

For every answer, list the files or links you used at the end. If you can't find a reliable source, say so instead of guessing.
