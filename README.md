# instructions

My saved instruction files, printed in the terminal by the `instruct` CLI.

```bash
instruct list      # list available instructions
instruct general   # print general.md
```

## Adding an instruction

1. Add `name.md` to this repo.
2. Add `name` as a new line in `index.txt`.
3. Commit and push.

Changes can take up to about 5 minutes to show up, because GitHub caches raw files.
